0 How to Use This Guide

Open Claude Code. Paste. Verify. Proceed.

Each prompt in this guide is a complete, self-contained instruction that can be pasted directly into Claude Code's chat interface. Prompts are written to be unambiguous — they include the exact file paths, table names, and validation criteria Claude Code needs to proceed without further clarification.

The guide is organized as a linear sequence within each phase. Work through steps in order. Each step ends with a Verify block — run that check before proceeding to the next step. If verification fails, do not continue; diagnose before building on a broken foundation.

Key File Locations (v1.1 Corrections)
Schema DDL: ./packages/core/src/vantage/db/schema.py — NOT data/schema.sql (old path). This is Python DDL, not raw SQL.
DB init — library: ./packages/core/src/vantage/db/init_db.py — the importable function.
DB init — CLI: ./scripts/init_db.py — what the /init slash command calls.
DataStore: ./packages/core/src/vantage/db/data_access.py — the correct location. Ignore ./packages/core/data_access.py (misplaced duplicate — resolved in step 0.0).

What to Harvest vs. What to Leave Behind

HealthSim ModuleActionRationale
db/connection.py — ConnectionManager ✓ Copy + adapt Close-before-write pattern, retry with exponential backoff, CHECKPOINT discipline. The hardest DuckDB problem, already solved.
db/data_access.py — DataStore interface ✓ Copy + adapt The abstraction that makes future Databricks/Snowflake portability possible. Strip HealthSim-specific query methods; keep the interface contract. Target: packages/core/src/vantage/db/data_access.py.
db/duckdb_store.py — DuckDBStore impl ✓ Copy + adapt Concrete DuckDB implementation of DataStore. Replace HealthSim schema references; keep the connection lifecycle logic.
Population generation framework ~ Structure only Copy the architecture (parameter validation, seeding, bulk insert pattern). Rebuild the domain content (MA demographics, HCC assignment) from scratch — HealthSim's entities are different.
TrialSim, RxMemberSim, NetworkSim ✗ Leave entirely Different domain. No reusable patterns specific to MA simulation.
NPPES import utilities ✗ Leave for now Phase 1 uses synthetic NPIs. Revisit in Phase 2 when real provider attribution matters.
Git LFS / .gitattributes ✗ Leave entirely Vantage never tracks .duckdb files in Git. No LFS needed.
